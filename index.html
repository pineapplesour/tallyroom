The problem

A cloud agent can only analyse your finances if you first hand your finances to the cloud. Most people, sensibly, will not do that.

What WebMCP changes

The page registers tools the agent can call. The data stays in the tab; only the questions and the answers cross the boundary.

What that feels like

You ask for the subscriptions you forgot about. It reads a thousand rows, filters your screen to the eight it found, and pins the total.
